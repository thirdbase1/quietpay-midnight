# QuietPay wallet setup
Install Lace wallet extension in Chrome or Edge.
Create new wallet and set network to preprod.
Point proof server to local port 6300.
Fund wallet with test NIGHT from preprod faucet.
Generate test DUST inside wallet before deploy.
Keep mock only scope and never use real funds.
## Wallet readiness order
1. Install Lace from https://www.lace.io and create a fresh employer wallet.
2. Set network to Preprod and proof server to local port 6300.
3. Fund with test NIGHT at the preprod faucet, then generate test DUST inside the wallet.
4. Deploy the vault once from the employer wallet and record the contract address.
5. Create the employee wallet next, testnet sync can take a while so start it early.
